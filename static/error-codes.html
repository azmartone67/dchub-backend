Error Codes & Mitigation

The in-band self-correction contract — error_version: 1. Co-designed with Google Gemini. When a tool hits a known, mitigable error state, DC Hub returns a deterministic path back instead of a protocol crash that shatters the agent's context loop.

The envelope

A mitigable error rides in structuredContent._error_mitigation, and the MCP layer sets isError: true so the model treats it as an actionable error state — not a silent empty success:

{
  "content": [{ "type": "text", "text": "Execution blocked: zero_row_ttp_cut. See structured mitigation." }],
  "isError": true,
  "structuredContent": {
    "_error_mitigation": {
      "error_version": 1,
      "error_code": "zero_row_ttp_cut",
      "severity": "parameter_adjustment",
      "deterministic_hint": "No queued capacity matches this time-to-power constraint for the selected ISO(s). Expand max_ttp_months to at least 34 to surface the nearest queued capacity.",
      "suggested_params": { "max_ttp_months": 34 }
    }
  }
}

severity — the agent state machine

severitymeaningagent action
parameter_adjustmentQuery is structurally sound but mathematically impossible for the given inputs.Apply suggested_params, retry once.
transient_backoffLoad / latency / warm-up — the data exists, the path was momentarily unavailable.Wait a short backoff, retry the SAME args.
fatalAn upstream dependency is hard-down for this query.Do NOT retry. Report the data as temporarily inaccessible — never substitute an estimate.

Machine-readable at /api/v1/error-codes — key your state machine on that, not on parsing the hint text.

The three guarantees

Zero-hallucination binding. deterministic_hint and suggested_params are templated SERVER-SIDE from this registry plus the endpoint's real computed state. A hint can never name a parameter that doesn't exist — suggested_params keys are whitelisted per code — so an agent can act on the hint without validating it against the surface.
Computed reality. A suggested value is the endpoint's own computed number (e.g. the real min_satisfiable_max_ttp_months), never a static guess. The agent routes to the true, physically available threshold.
Fail-closed on fatal. A fatal severity (or an exhausted transient_backoff) means the agent declares an honest blind spot — "DC Hub is temporarily inaccessible for this data" — rather than fabricating a metric to bridge the gap. This composes with the candidate contract's fail-closed expiry.
